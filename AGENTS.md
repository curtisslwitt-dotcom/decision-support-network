# Mandatory standard for all future DSA builds

Curtiss Witt requires DSN telemetry in every future build (2026-10-20). Read and apply [operations/DSN_TELEMETRY_STANDARD.md](operations/DSN_TELEMETRY_STANDARD.md) when building a new property or preparing build/retrofit instructions for any agent or developer. Use the property's own registered ID, preserve existing telemetry, and exclude all personal data and answers.
